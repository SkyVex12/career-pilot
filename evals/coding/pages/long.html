Busiest Window

Our API gateway writes one log line per request with the second it arrived at. To size the rate limiter, the platform team wants to know the busiest stretch of traffic: the largest number of requests that arrived within any window of window consecutive seconds.

You are given the arrival times as an array timestamps of integers (seconds since the gateway started). The array is not sorted and may hold the same second many times: several requests can arrive in one second.

A window starting at second s covers the seconds s, s + 1, ..., s + window - 1, so a request at second t is inside it when s <= t < s + window. The window may start at any second, not only at an arrival.

Return the largest number of requests inside any one window.

Function description

Complete the function busiest_window in the editor below. It has the following parameters:

  • int timestamps[n]: the arrival seconds, in any order
  • int window: the window's length in seconds

It returns an int: the largest number of requests in one window.

Example 1

timestamps = [10, 1, 3, 2, 11]
window = 3
returns 3   (the window 1..3 holds the requests at 1, 2 and 3)

Example 2

timestamps = [5, 5, 5]
window = 1
returns 3

Example 3

timestamps = [1, 4, 7]
window = 2
returns 1

Constraints

  • 1 <= n <= 2 * 10^5
  • 0 <= timestamps[i] <= 10^9
  • 1 <= window <= 10^9
  • Your solution must run in O(n log n) time or better.

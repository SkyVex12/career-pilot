Pairs With Gap K

Hash Map

Given an integer array nums and an integer k, return the number of distinct pairs of values (a, b) with a <= b, both present in nums, such that b - a == k.

A pair counts once however many times its values appear. When k == 0, a pair (a, a) counts only if a appears at least twice.

Example 1

nums = [3, 1, 4, 1, 5], k = 2
returns 2      // (1, 3) and (3, 5)

Example 2

nums = [1, 2, 3, 4, 5], k = 1
returns 4

Example 3

nums = [1, 3, 1, 5, 4], k = 0
returns 1      // (1, 1)

Constraints

  • 1 <= nums.length <= 10^5
  • -10^7 <= nums[i] <= 10^7
  • 0 <= k <= 10^7

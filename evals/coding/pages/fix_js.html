Debug: Sorted Search

DebuggingBinary Search

search(nums, target) should return the index of target in the sorted array nums of distinct integers, or -1 if it is not there, in O(log n) time.

The implementation on the right never returns for some inputs and returns wrong answers for others. Find the bug and fix it. Keep the function's name and signature.

Expected

search([1, 3, 5, 7], 7)   // 3
search([1, 3, 5, 7], 4)   // -1
search([], 1)             // -1
search([2], 2)            // 0
search.jsJavaScriptRun
function search(nums, target) {
  let lo = 0, hi = nums.length;
  while (lo <= hi) {
    const mid = Math.floor((lo + hi) / 2);
    if (nums[mid] === target) return mid;
    if (nums[mid] < target) lo = mid;
    else hi = mid - 1;
  }
  return -1;
}

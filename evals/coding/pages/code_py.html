1834. Merge Booking Windows

MediumSortingArrays

A meeting room's bookings are given as windows, where windows[i] = [starti, endi]. Two windows overlap or touch when one starts at or before the other ends.

Merge every group of overlapping or touching windows into one, and return the merged windows sorted by start.

Example 1:

Input: windows = [[1,3],[2,6],[8,10],[15,18]]
Output: [[1,6],[8,10],[15,18]]
Explanation: [1,3] and [2,6] overlap, so they become [1,6].

Example 2:

Input: windows = [[1,4],[4,5]]
Output: [[1,5]]
Explanation: the windows touch at 4.

Example 3:

Input: windows = [[6,8],[1,2],[2,3]]
Output: [[1,3],[6,8]]

Constraints:

  • 1 <= windows.length <= 104
  • 0 <= starti <= endi <= 104
